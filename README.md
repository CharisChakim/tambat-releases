# Tambat releases

Installers and the auto-update feed for **Tambat**, the lightweight Termius alternative for SSH and SFTP.

- **Download:** <https://tambat.world/#unduh> or the [latest release](https://github.com/CharisChakim/tambat-releases/releases/latest)
- **Open-source Community Edition:** <https://github.com/CharisChakim/tambat-ce>
- **Support:** support@tambat.world

This repository only hosts release files. Tambat's source code is not published here.

## Installing

The installers are not code-signed with a commercial certificate yet.

- **Windows:** if SmartScreen appears, choose **More info → Run anyway**.
- **macOS:** if macOS blocks the first launch, open **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Linux:** use the `.AppImage` (make it executable), `.deb`, or `.rpm`.
